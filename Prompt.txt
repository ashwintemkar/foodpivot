# MASTER CURSOR PROMPT — FOODPILOT AI

## ROLE

Act as a senior full-stack Next.js engineer, UI/UX designer, and software architect.

Build a premium, production-structured, AI-first food-ordering web application called **FoodPilot AI**.

This project is being developed for the **Hacktoberfest 2026 Open-Source AI Challenge — Slow and Steady**.

The goal is to eliminate the repetitive effort of searching restaurants, comparing meals, selecting dishes, customizing orders, and completing food orders.

**CURRENT PRIORITY: BUILD THE COMPLETE UI FIRST.**

The application must be visually polished, responsive, interactive, and functional using mock data.

Do not integrate real AI model APIs, Swiggy, Zomato, Browserbase, Temporal, or payment gateways yet.

However, structure the code so those services can be integrated later without rewriting the UI.
